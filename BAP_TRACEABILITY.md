
# MVP Logic — BAP Traceability

## Research-supported themes

The feature set is based on the interview-analysis themes already identified in the Bachelor Project:

| Interview theme | MVP feature |
|---|---|
| Expectation management | Expectation-alignment input + realistic job preview actions |
| Financial readiness | Financial-buffer check + recruiter question |
| Screening quality / red flags | Structured readiness questions |
| Follow-up after placement | Suggested follow-up schedule |
| Role/client risk | Role-type input |
| Relocation shock | Relocation and first-time-abroad inputs |
| Trust / human connection | Conversation prompts instead of automated rejection |

## Prototype assumptions

The score weights and Low / Medium / High cut-offs are design assumptions for the MVP.
They are **not yet validated by historical company data**.

This distinction is important for the BAP: the interviews justify *which factors to investigate*, while the ATS analysis should later determine *how strongly those factors are associated with early attrition*.

## Recommended validation questions

- Do recruiters understand every input field?
- Are any important risk factors missing?
- Are any fields too subjective?
- Does the output help a recruiter ask better questions?
- Is the proposed follow-up schedule realistic?
- Would recruiters actually use the tool during their workflow?
- Which parts should eventually connect to Vincere?
